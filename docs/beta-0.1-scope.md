# TOMOS Beta 0.1 Scope

TOMOS Beta 0.1 is an API-ready demo of a private AI Brand Operating System.

## Included

- Private Command Center UI
- Always-on AI Engine structure
- Executive Brief
- Approval Center with local state actions
- Brand Portfolio
- Broadcast Center with local preparation state
- Content Review AI with rewrite application
- SNS Health
- Commerce Analytics
- Product Opportunity
- Knowledge Vault
- 24h Activity Timeline
- AI Decision Log
- Automation Rules
- `/api/health` endpoint

## Not Included Yet

- Production authentication
- Database persistence
- External API connections
- Background cron execution
- Encrypted SNS or commerce tokens
- Multi-user isolation

All dashboard data is sample data. User actions are reflected only in browser state and reset on refresh.
