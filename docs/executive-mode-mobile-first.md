# Executive Mode Mobile First

TOMOS Beta 0.2 introduces Executive Mode.

## Concept

TOMOS is not a desktop work tool. It is a private AI Operating System that an executive can check from iPhone in about five minutes.

The design target is:

- Apple Watch-like information density
- Dynamic Island-like status presence
- Vision Pro-like depth and glass
- Linear-like restraint
- Arc-like operating system feel

## Mobile First Home

The first screen focuses on:

- Good Morning, Tom.
- TODAY
- AI running 24 hours
- System Health
- Today's Executive Brief

Everything else is secondary.

## Approval Queue

The approval queue is the primary operating surface.

- Right swipe: approve
- Left swipe: hold
- Long press: detail
- Tap buttons remain available as a fallback for accessibility and desktop

## Responsive Modes

- Desktop: Operating Center
- Tablet: Manager Mode
- Mobile: Executive Mode

## Future Connections

Executive Mode is designed for OpenAI, Anthropic, Google, YouTube, Instagram, Threads, Pinterest, Shopify, BASE, Mercari, Google Analytics, Search Console, GitHub, Vercel, Slack, Notion, and Cron connections.

Until those integrations are live, TOMOS uses mock data and local browser state.
