# Privacy And Publication Model

TOMOS is private by default.

## Private Data

- Registered brands
- SNS account data
- Sales data
- AIO scores
- AI improvement notes
- Approval queues
- Operation logs
- Draft content

## Public Data

Only explicitly approved assets can be published:

- Articles
- Videos
- SNS posts
- Brand pages marked public by the user

## Required Production Behavior

No automated public posting should occur without a user approval record. Every publication should have an audit trail with user, timestamp, target channel, and final asset.
