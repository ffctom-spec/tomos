# Knowledge Vault

Knowledge Vault stores content as reusable knowledge assets instead of one-off posts.

## Asset Types

- FAQ
- Glossary
- Comparison tables
- Summary blocks
- Product paths
- SNS adaptations
- Podcast scripts
- YouTube scripts
- Blog sections
- AI citation blocks

## Purpose

Every approved Broadcast Mission should become a durable asset that supports AIO, SNS reuse, commerce, and future content production.
