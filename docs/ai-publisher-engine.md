# AI Publisher Engine

The AI Publisher turns TOMOS from a dashboard into a daily operating system.

## Responsibilities

- Monitor research sources
- Generate Daily Brief items
- Select Broadcast Missions
- Route content to the right brand
- Prepare channel-specific drafts
- Convert content into Knowledge Vault assets
- Watch performance after publication
- Feed results back into the Learning Loop

## Production Inputs

- Search trends
- YouTube and Shorts performance
- Instagram and Threads metrics
- Pinterest saves
- Commerce conversion data
- User-approved brand strategy

## Output

The user sees a small set of executive decisions rather than raw operational tasks.
