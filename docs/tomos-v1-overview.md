# TOMOS v1 Overview

TOMOS v1 is a private AI Brand Operating System for logged-in users.

The product is not a public brand website. It is a Command Center where AI engines research, analyze, review, route, publish-prep, learn, and surface only executive decisions to the user.

## Operating Principle

- The user owns the brands and data.
- Default visibility is private.
- AI prepares recommendations and next actions.
- The user chooses approve, request revision, hold, or reject.
- External publication happens only after explicit approval.
