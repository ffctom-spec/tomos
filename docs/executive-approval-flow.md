# Executive Approval Flow

Executive Approval is the only place where the user should need to act.

TOMOS should do the research, analysis, writing, routing, scoring, and improvement work. The user sees only the filtered queue of decisions that require judgment.

## Approval Types

- 公開承認
- リライト承認
- 商品提案承認
- 配信テーマ承認
- AIO改善承認

## Actions

The user can choose:

- 承認
- 修正依頼
- 保留
- 却下

## Flow

1. An AI engine detects an opportunity or issue.
2. TOMOS creates the proposal and supporting rationale.
3. The Approval Engine filters the queue.
4. The user selects one of the approval actions.
5. TOMOS executes or revises the asset.
6. The Learning Loop monitors results after publication.

## Publication Rule

Nothing should become externally visible until the user approves publication.

Approved assets may become public content. Private scores, logs, SNS data, EC data, drafts, and decision rationale remain private.
