# Brand Portfolio Strategy

TOMOS manages user-owned brands as a private portfolio.

## Sample Registered Brands

- VERDNA: plants, dry garden, Knowledge Cast
- YUGAWA Residence: home assets, exterior, garden, interior, DIY
- PAJOUR: personal brand, design, DJ, cooking, lifestyle
- titi&joji: pets, California lifestyle, SNS

These are sample registered brands inside a private workspace, not public brand pages.

## Brand Routing

AI recommends which brand should publish each theme based on:

- Topic fit
- Audience expectation
- AIO opportunity
- SNS format
- Commerce path
- Existing knowledge assets
