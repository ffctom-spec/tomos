# Knowledge Cast Format

Knowledge Cast is an AI-narrated knowledge program designed to be listened to passively.

## First Themes

- 0円でできる土壌改良
- ロストラータを太く育てる方法
- アガベの発根
- ドライガーデンの水やり
- 野菜作りの先人の知恵

## Format

- Calm opening
- One clear question
- Short expert explanation
- Practical steps
- Common mistakes
- FAQ block
- Next action or product path

The script should be reusable as article sections, YouTube narration, Podcast audio, and FAQ assets.
